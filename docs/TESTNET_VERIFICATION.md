## Instructions for Deploying Contracts to Testnet

To deploy real instances of `IdentityRegistry` and `SelectiveDisclosure` to testnet:

1. **Build WASM binaries**:
   ```bash
   cd smart-contracts
   stellar contract build
   ```
2. **Deploy to Testnet**:
   ```bash
   # Create a testnet identity if not present
   stellar keys generate alice --network testnet
   stellar keys fund alice --network testnet

   # Deploy IdentityRegistry
   stellar contract deploy \
     --wasm target/wasm32-unknown-unknown/release/identity_registry.wasm \
     --source alice \
     --network testnet

   # Deploy SelectiveDisclosure
   stellar contract deploy \
     --wasm target/wasm32-unknown-unknown/release/selective_disclosure.wasm \
     --source alice \
     --network testnet
   ```
3. Copy the returned contract IDs (`C...`) into `frontend/.env` and `backend/.env`.
